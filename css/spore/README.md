# Spore

Select `spore` in the appearance menu or append `?theme=spore` to the site URL.

## Layout and interactions

- Fixed desktop navigation rail; stacked navigation on small screens.
- Independent account controls with admin search and the existing keyboard shortcut.
- Asymmetric mushroom portal, offset light reading island, and a links garden below the content.
- Three slowly rotating mechanical mandalas. Pause the cosmos stops animation and remembers the choice when local storage is available. OS reduced-motion preferences always take precedence.
- Find the canopy fairy, root gnome, and reading fairy. Each has a keyboard-accessible button and a different reply; discovering all three unlocks a final message. No sound or external services.
- Store tokens follow the reading island, including when the operating system uses dark mode.
