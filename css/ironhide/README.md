# Ironhide

Select `ironhide` in the appearance menu, or use `?theme=ironhide`.

A self-contained theme with a charcoal workshop exterior, copper accents, warm canvas content surfaces, responsive account navigation, and matching store styling. Shared CMS assets are loaded through `ghoti.header.php`; artwork and theme-specific code live here.

## Artwork

Generated with the built-in imagegen tool. The images are decorative editorial artwork, not photographs of actual premises or products. Original PNGs are included locally:

- `images/workshop.png`: hero artwork, 1536 × 1024.
- `images/workbench.png`: supporting workshop still life.
