# Veil

Select `veil` in Appearance or append `?theme=veil` to the site URL.

An esoteric research desk: file-tab navigation, a layered paper dossier, a taped evidence plate, a geometric instrument, cross-references, and a bottom utility dock. The fictional archive aesthetic draws on Renaissance notebooks, intelligence files, celestial geometry, grey-alien imagery, and Celtic woodland ornament.

## Interactions

- Reading lamp hides the exhibit column and expands the document. Restore exhibits reverses it.
- Geometry, Cosmos, and Grove change the instrument's orientation and explanatory text.
- A note in the margin opens with a native details control.
- The artwork opens at full resolution in a new tab.
- Existing account/admin tools and Ctrl/Cmd K remain available.
- Mobile layout stacks the document and exhibits; reduced motion disables instrument transitions.
