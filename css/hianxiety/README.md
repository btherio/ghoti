# Hi Anxiety

Select `hianxiety` in Appearance or append `?theme=hianxiety` to the site URL.

A storefront-first theme drawn from the supplied Hi Anxiety wordmark: black space, liquid chrome, orbital geometry, hard-edged merchandising panels, and a restrained acid signal colour. It includes responsive public navigation, the account/admin workspace, dedicated catalogue and store-management styling, reduced-motion support, and print fallbacks.

## Artwork

The theme uses the supplied `gfx/hatco-logo3.png` as its primary wordmark. The image remains in `gfx` as the canonical brand asset and is displayed without colour filters so its original black-and-white artwork is preserved.
