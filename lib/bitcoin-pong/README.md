# Bitcoin Pong

A dependency-free, single-player Pong game for Linux terminals. Defend the left
side against the CPU and be the first to mine seven points. The ball is a gold
Bitcoin emblem (`₿`).

## Play

```bash
cd /home/bryan/bitcoin-pong
./bitcoin_pong.py
```

Controls:

- `W` / `S` or arrow keys — move your paddle
- `P` — pause
- `R` — restart the match
- `Q` or `Esc` — quit

Python 3 and a terminal at least 54 columns by 18 rows are required.
